# 🚗 Car Rental System (Java OOP Project)

## 📌 Project Overview

The **Car Rental System** is a console-based Java application designed using **Object-Oriented Programming (OOP)** principles. The project simulates a real-world car rental service where users can view available cars, rent a car, return a car, and calculate rental charges.

This project is ideal for beginners who want to understand how OOP concepts work together in a practical application.

---

## 🛠️ Technologies Used

* **Language:** Java
* **Concepts:** OOP (Object-Oriented Programming)
* **IDE:** VS Code
* **Java Version:** JDK 17

---

## 🎯 OOP Concepts Used

* **Class & Object** – To model real-world entities like Car, Customer, and RentalService
* **Encapsulation** – Using private variables with getters and setters
* **Inheritance** – To extend common properties (if applicable)
* **Polymorphism** – Method overriding and flexible method usage
* **Abstraction** – Using abstract classes or interfaces for system design

## ▶️ How to Run the Project

1. Clone or download the project
2. Open the project in any Java IDE
3. Compile all `.java` files
4. Run the `Main.java` file

```bash
javac Main.java
java Main
```

---

## 🧪 Sample Flow

1. User selects an option from the menu
2. System displays available cars
3. User rents a car by entering required details
4. System calculates total rent
5. User can return the car
